# Contributing

Issues and pull requests are welcome. Describe the problem and intended behavior, and keep changes focused. For hardware reports include the modem model, firmware revision, Windows version and relevant redacted logs. Never share phone numbers, IMEI, SIM identifiers, message contents, PINs or PUKs.

Build with the .NET 8 SDK using `dotnet build -c Release`. Explain how you verified a change, and distinguish automated checks from testing with a physical modem. Do not submit carrier firmware, proprietary drivers, private data or generated binaries in pull requests. Follow the existing code style and respect other contributors.
